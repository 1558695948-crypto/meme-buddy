# MoSo 通用表情包 · 32枚

形象：白色低多边形折纸兔头、黑色西装、白衬衫与橙色背景。基于用户提供的 MoSo 品牌形象参考，通过内置 imagegen 生成四张 4×2 母版，再按固定网格分切导出。

`assets/` 中的32张 JPG 是用于聊天的独立图片，每张384×384；`sheets/` 保留生成母版；`overview.jpg` 用于总览；`manifest.json` 包含图片校验值、情绪、意图、文字、适用提示与来源。

在仓库根目录运行：

```bash
python3 tools/import_sample_pack.py --pack moso-pack
```

图库在 `~/.meme-buddy/`，导入不覆盖使用偏好。Skill 可通过 `MoSo` 或具体情绪/意图检索。

本套为静态表情，不包含动画。“正在处理”“安排上了”“搞定”等短句只能搭配真实状态，不能用来冒充任务进展。

本次制作、本地入库及上传权利方GitHub仓库由用户授权；第三方商用与再分发许可仍由 MoSo 权利方决定。
