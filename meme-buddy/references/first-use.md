# Pick a starter collection on first use

The AI chooses its own expressive repertoire with this user: up to 20 images, not a fixed menu of emotions or an approval questionnaire. This is a first-activation workflow, not an installer side effect or background task.

1. Run `python3 <skill-dir>/scripts/meme_buddy.py onboarding-status` for the selected library. If complete, continue normal use. If an existing collection already reflects this conversation, reuse it rather than automatically fetching another set. Updates/reinstalls must not reset completion.
2. Read only conversation context and preferences actually available. Notice humor, style, recurring shared topics, and your own taste. Do not claim access to all prior chats, read unrelated private conversations, or infer sensitive personal traits. With little context, choose a small versatile collection you like and refine naturally later.
3. If collecting will take noticeable time, briefly say so; do not lead with a long setup report. Use the host's available web/image search and downloader to find images. Search with generic style/reaction terms; never send private dialogue, names or user-specific secrets to a search service. No fixed categories, mandatory exact count, forced questionnaires or per-image approval gates. Choose images you would actually reach for, not one image per predefined emotion. A ready existing library can supply the first reaction before further collection.
4. Download and inspect candidates in a dedicated staging folder. Collect at most 20 accepted unique images in this onboarding session; stop when the selection feels useful. Deduplicate using ingest, check actual format and multi-frame status for claimed animations, and prefer files that display promptly. If large GIFs are especially fitting, retain them with honest size metadata rather than calling them lightweight. Record source URLs and known rights without inventing commercial permission. Do not automatically publish collected files.
5. Use the normal `ingest` and `annotate` flow. Have the AI describe the visible content and actual meaning. No search/generation tool or no usable downloads means a deferred setup: explain the limit once, use existing assets if available, and do not mark an empty failed collection as complete or retry on every message. Resume when the user asks or the missing capability becomes available.
6. Record only accepted IDs with `python3 <skill-dir>/scripts/meme_buddy.py onboarding-complete --ids <id1> <id2> ...`. The CLI verifies 1–20 distinct annotated, existing assets. Store completion outside the Skill folder, with no raw conversation or private profile. Demonstrate a fitting favorite using [delivery.md](delivery.md); mention the count only if useful. The user does not need to approve every selection. Choosing fewer than 20 is normal; do not pad to the limit.

The limit applies to the initial self-curated collection, not the whole library. User-imported packs such as 32 MoSo stickers remain valid. Later additions happen naturally when requested or appropriate to an ongoing task, not as a forced recurring collection job.
